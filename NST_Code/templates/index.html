Neural Style Transfer Studio
How it works

Repaint any photo in the style of an artwork

Neural Style Transfer uses a deep neural network to separate what an image shows (its content) from how it is painted (its style), then recombines the content of your photo with the style of a painting. This studio uses the AdaIN method, which needs only one forward pass of the network, so a result takes about a second or two.

How it works

Arbitrary style transfer with Adaptive Instance Normalization (Huang & Belongie, ICCV 2017).

1. Encode

Both images are resized so the shorter side is {{ processing_size }} px and passed through a pretrained VGG-19 network up to layer relu4_1, giving 512 feature maps each.

2. Match statistics

AdaIN normalizes each content feature map and re-scales it with the style's mean and standard deviation: σ(s)·(c − μ(c)) / σ(c) + μ(s).

3. Blend

Style strength α mixes the result with the original content features: α·AdaIN + (1 − α)·content.

4. Decode

A decoder network, trained to invert VGG features, turns the blended features back into an image.

Results are generated at the model's working resolution (shorter side {{ processing_size }} px). Uploaded images are deleted right after processing, and results are deleted automatically after one hour.

Based on shradha-khapra/ai-nst-project (model code and trained decoder). Method: X. Huang and S. Belongie, “Arbitrary Style Transfer in Real-time with Adaptive Instance Normalization”, ICCV 2017.
